Swarm throughput

Answer tokens are the tokens askers receive. Served tokens are tokens any phone ran its block on, prompt tokens included, so every answer token counts once per block. Rates are over the last minute.

Blocks

Capacity is how many generated tokens per second the block's phones could run if they did nothing else: the sum of 1000 ÷ compute ms per token. The block with the least capacity limits the swarm.

Phones

Utilization is the share of the last minute the phone spent computing, from the compute time it reports. Hop time is measured by the tracker, from forwarding a frame to the phone until its answer comes back, so it includes the network; network = hop time − compute.
